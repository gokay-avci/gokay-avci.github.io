evokUPS

Batched evolutionary pre-packing of polydisperse polymer chains with differentiable forces.

Reduced units: bead diameter σ, energy ε, density ρ* = Nσ³/V, pressure P* = Pσ³/ε, temperature T* = kBT/ε. Θbridge/ε is an algorithmic acceptance scale, not a physical temperature. The local pressure controller changes one shared isotropic cell between generations, preserving the fixed [population, beads, 3] batch. Set κg to zero for a fixed-volume search. External kUPS keeps JAX hot, so its cell is fixed for the session.
