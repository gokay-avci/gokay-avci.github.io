# About Voxel Space.

My work focuses on the deterministic simulation of stochastic physical processes. By moving scientific kernels from legacy Fortran/Python to **Rust**, we gain memory safety without sacrificing performance.

### Technical Stack

| Area | Technologies |
| :--- | :--- |
| **Languages** | Rust, Python, C++, GLSL |
| **Web** | WebAssembly, Trunk, Zola, Tokio |
| **Science** | Molecular Dynamics, Monte Carlo, DFT |
| **Tools** | Git, Docker, LaTeX, Blender |
